使用方法

  1. 在「播放设备」里确认你的音响已被发现（没有就点「重新扫描」，最多等 30 秒）。
  2. 不需要的播放器（例如电视、投影）把「启用」关掉。
  3. 在 iPhone / iPad / Mac 的控制中心里点 AirPlay，选择音响名（带后缀的那个）。
  4. Sonos / Heos 用户请在「设置」里把延迟改成 Sonos / Heos 预设。
